# Websites

Case studies for three WordPress storefronts built for Bangladeshi retail:
NoriBD (seafood), Bangu Bhozon (multi-category), and Cafe Neptune (cafe
takeaway).

Live page: https://ahnafmohsieu.github.io/Websites/

## Status

The original Pantheon staging environments have been deleted, so there is no
working public demo. A WordPress shop needs PHP and MySQL, which GitHub Pages
cannot run. The full build for each site exists as an All-in-One WP Migration
archive (350–530 MB) and is available on request — those files exceed GitHub's
100 MB per-file limit, so they are not in this repository.

`IMPORT.md` documents restoring an archive onto any PHP host.

## Editing

`index.html` is hand-written and `styles.css` holds the design tokens. No build
step. The page is served from `main` / `/ (root)` by GitHub Pages.
